# v1.1.0

## Changes

- Add `:is()` and `:where()` with forgiving selector lists and the corresponding specificity rules.
- Add `:any-link`, the explicit `s` attribute flag, and `:nth-child(An+B of S)` / `:nth-last-child(An+B of S)`.
- Stop matching links with `:enabled`; form-control behavior is retained.
- Escape quotes and backslashes in serialized `:contains()` arguments and leading digits in serialized ID/class selectors.
- Ignore CSS comments while recovering invalid `:is()` / `:where()` arguments, so comment contents cannot become selector alternatives.
- Use a byte lookup table for class-list whitespace. No performance gain is claimed without a workload-specific measurement.
- Update `golang.org/x/net` from v0.55.0 to v0.63.0 and the minimum Go version from 1.25 to 1.26.
- Run current reporting checks on Go 1.27.4 and verify the minimum Go 1.26 toolchain in CI.

The fork's indexed query APIs remain available. Filtered sibling-position
selectors use ordinary matching because existing sibling indexes do not
represent arbitrary `of` selector subsets. Regression tests compare indexed
and ordinary queries, including nested selectors and subtree indexes.

## Install

```sh
go get github.com/soulteary/cascadia@v1.1.0
```

Consumers need Go 1.26 or later. Existing module paths and public API names
are retained. `:enabled` no longer matches `a`, `area`, or `link` elements
solely because they have `href`; use `:link` or `:any-link` for those elements.
